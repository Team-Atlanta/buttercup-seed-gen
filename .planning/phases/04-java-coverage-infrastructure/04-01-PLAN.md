  <name>Task 2: Install JaCoCo JARs in builder-coverage.Dockerfile</name>
  <files>oss-crs/dockerfiles/builder-coverage.Dockerfile</files>
  <action>
Add JaCoCo installation to builder-coverage.Dockerfile. Download JaCoCo release (0.8.11 or latest stable) and extract agent and CLI JARs to /opt/:

```dockerfile
# Install JaCoCo for Java coverage
ARG JACOCO_VERSION=0.8.11
RUN curl -fsSL "https://repo1.maven.org/maven2/org/jacoco/jacoco/${JACOCO_VERSION}/jacoco-${JACOCO_VERSION}.zip" -o /tmp/jacoco.zip && \
    unzip -j /tmp/jacoco.zip "lib/jacocoagent.jar" -d /opt/ && \
    unzip -j /tmp/jacoco.zip "lib/jacococli.jar" -d /opt/ && \
    mv /opt/jacocoagent.jar /opt/jacoco-agent.jar && \
    mv /opt/jacococli.jar /opt/jacoco-cli.jar && \
    rm /tmp/jacoco.zip
```

Place this after base image setup but before COPY/entrypoint commands.
Ensure unzip is available (add to apt-get install if needed).
  </action>
  <verify>docker build -f oss-crs/dockerfiles/builder-coverage.Dockerfile . --target=base 2>&1 | grep -v error || echo "Build started"</verify>
  <done>Dockerfile contains JaCoCo installation, JARs will be at /opt/jacoco-agent.jar and /opt/jacoco-cli.jar</done>
</task>
