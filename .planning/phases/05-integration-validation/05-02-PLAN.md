  <how-to-verify>
If a Java target is available:

1. **Build the Java target:**
```bash
cd ~/post/oss-crs-6 && source .env && uv run oss-crs build-target \
    --compose-file example/buttercup-bugfind/compose.yaml \
    --fuzz-proj-path {JAVA_TARGET_PATH}
```

2. **Run coverage-bot:**
```bash
cd ~/post/oss-crs-6 && source .env && uv run oss-crs run \
    --compose-file example/buttercup-bugfind/compose.yaml \
    --fuzz-proj-path {JAVA_TARGET_PATH} \
    --target-harness {JAVA_HARNESS_NAME}
```

3. **Check coverage-bot logs for Java coverage:**
```bash
COVERAGE_BOT=$(docker ps --filter "name=coverage-bot" -q | head -1)
docker logs "$COVERAGE_BOT" 2>&1 | grep -i "java\|jacoco\|coverage" | tail -30
```

4. **Verify JaCoCo XML was generated:**
```bash
docker exec "$COVERAGE_BOT" ls -la /artifacts/coverage/dumps/*.xml 2>/dev/null
```

5. **Check CoverageMap in Redis:**
```bash
docker exec $(docker ps --filter "name=redis" -q | head -1) redis-cli KEYS "*coverage*" | head -10
```
