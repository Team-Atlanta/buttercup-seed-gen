  </what-built>
  <how-to-verify>
    After deployment is running (from Task 1):

    **Step 1: Check corpus directory for seeds**
    ```bash

    docker exec $CONTAINER ls -la /artifacts/corpus/
    # Expected: Files with SHA256 hash names (e.g., a1b2c3d4...xyz)
    # Count: Should be non-zero after seed-gen runs
    ```

    **Step 2: Count generated seeds**

    ```bash

    ```

    **Step 4: Check seed-gen logs for generation activity**
    ```bash
    docker logs $CONTAINER 2>&1 | grep -i "seed\|corpus" | tail -20
    # Expected: Seed generation messages
    ```

    - CODE-05: libCRS submission log shows activity OR process is running
